# 固定ページ・データの文言の翻訳（ko・fr・es）— 作業指示書

対象：`D:\OneDrive\01_仕事・事業\M16BIZ\waysidejapan` の `src/i18n/pages/*.ts` と `src/i18n/data/*.ts`（英語の表 `table.en` が原本）。
目的：各モジュールの `table` に、**ko・fr・es** の表を足す。台湾向け（zh-tw）は今回は対象外（表を足さない）。

## 0. 守ること
- 言語ごとのスタイルガイド・用語集に**すべて従う**：`docs\TRANSLATION-KO.md` / `TRANSLATION-FR.md` / `TRANSLATION-ES.md`（文体、固有名詞、官庁名、用語、§6 追加用語）。
- **担当は「モジュール単位」**。依頼文で指定されたファイルだけを編集する（ほかのファイル、`translations-draft/`、`src/config.ts`、`LOCALES` は触らない）。同じファイルを触る人は他にいない。
- git・ビルド・デプロイ・Web検索はしない。`LOCALES` は `['en']` のまま。
- **キーの形は英語と完全に同じにする**：キーの過不足なし、関数は関数のまま（引数の数と意味を変えない）、配列の要素数も同じ、空文字にしない。`as const` や型の書き方は、既存の `en` に合わせる。
- 英語の表（`table.en`）は**変更しない**。他言語の表は、同じファイルの `table` に `ko: {...}` `fr: {...}` `es: {...}` として足す（`table = { en, ko, fr, es }`）。

## 1. 翻訳の規則
- **事実を足さない・変えない・落とさない。** 数字・日付・金額・固有名詞・出典の言い方を、原文の強さのまま訳す。一人称の筆者（I）の声を保つ。説教調にしない。
- 関数（`(n) => \`${n} guides\`` など）は、**言語ごとの語順・複数形・冠詞に合わせて**中身を書き換えてよい（引数は同じものを使う）。
- **`{{name}}` の置換記号、HTML の断片（`<a>` `<strong>` `<em>` `<code>` `<br>`）、`href` の記号は、位置と数を変えず、そのまま残す。** タグの中の文字だけ訳す。
- 翻訳しないもの：ブランド名・サイト名・URL・コード・数値・記号・漢字1字の意匠・日本語のまま載せる約束の語（統計の定義文、チェーン名・商品名）。
- 日付の書式や桁区切りは、既存の関数（`dateTagOf` など）に任せ、文字列に直書きしない。
- 訳文の長さがレイアウトを壊さないよう、見出し・ボタン・タイルの文言は、英語と同程度の長さに収める。
