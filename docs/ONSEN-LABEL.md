# 温泉ランク運用ルール（S / A / B / C）

**決定日**：2026-10-10（村瀬さん承認。ランク制・B/Cも公開表示）
**要確認（暫定で進めた2点）**：A の名称を「かけ流し（加水・加温あり）」とした点、C を「循環あり」と定義した点。村瀬さんが別案なら変更する
**根拠となる調査**：`docs/research/onsen-kakenagashi-2026-10-10.md`、`docs/research/onsen-quality-2026-10-10.md`

## 1. ランクの定義

判定は **4つの条件の組み合わせ**で機械的に決める。評価語（良い・悪い）ではなく、条件の表示である。

| ランク | 英語表示 | 名称 | 加水 | 加温 | 循環 | 塩素消毒 |
|---|---|---|---|---|---|---|
| **S** | `S · Source-only` | 源泉100%かけ流し | なし | なし | なし | なし |
| **A** | `A · Free-flowing` | かけ流し（加水・加温あり） | どちらか、または両方あり | ← 同左 | なし | なし |
| **B** | `B · Free-flowing, chlorinated` | かけ流し＋塩素消毒 | あり得る | あり得る | なし | あり |
| **C** | `C · Recirculated` | 循環あり | — | — | あり | — （消毒の方式は注記） |

- **S**：加水・加温・循環・消毒の4つがすべて「なし」と確認できたもの
- **A**：循環なし・消毒なしで、加水か加温の少なくとも一方がある（「源泉100%」とは名乗らない。加水・加温があれば「源泉100%」は不当表示になり得る＝公正取引委員会 2003年見解）
- **B**：循環なしのかけ流しだが、塩素消毒がある
- **C**：循環ろ過がある（塩素消毒の有無・方式は「注記」に事実で書く。例: 塩素、紫外線、オゾン）
- **ランク無し（`Unrated`）**：4条件のどれか1つでも確認できなければ、ランクを付けない。その施設は記事にしても、ランク表示は出さない

### 定義が独自である理由（凡例に3行で必ず書く）

- 「源泉かけ流し」に**法令上・公的な定義は確認できていない**（環境省等の資料の範囲。条文の逐語照合は未了）
- 日本温泉協会（民間団体）の用語は「かけ流し」「源泉かけ流し（加水なし）」「源泉100%かけ流し（加水・加温なし）」で、**塩素消毒には触れていない**。本サイトの「塩素消毒なし」は独自の追加条件
- **循環や塩素消毒は、衛生上の理由で必要になる場合がある**（法令・指針で義務づけられる施設もある）。環境省の小委員会も「どちらが本質的に優れるとは言えない」という立場。ランクは**入浴体験の好み**（源泉に近いかどうか）の指標であり、施設の衛生や安全を評価するものではない

## 2. 付与条件（どちらか1つ）

- **A. 公式WEB**：施設・宿の公式サイトに記載がある（AIによる確認でも可）
- **B. 現地確認**：運営者（村瀬さん）が現地で確認した

### 公式WEBの文言判定（AI確認時はこの表で機械的に判定する）

| 公式サイトの文言 | 判定 |
|---|---|
| 加水・加温・循環・消毒の各有無が**明記**されている | その内容でランクを付ける |
| 「源泉100%」＋「加水・加温・循環・消毒なし」が明記 | **S** |
| 「源泉かけ流し」だけ | **ランク無し**（加温・消毒の有無が分からない） |
| 「天然温泉」「かけ流し（一部循環）」など曖昧・限定つき | **ランク無し**（一部循環は C の条件に当たり得るので、詳細が分かるまで付けない） |
| 記載が見つからない | **ランク無し**（温泉法18条・施行規則10条の掲示義務は、加水・加温・循環・消毒を「行っている場合」にのみ生じる。掲示が無い＝無添加とは言えない） |

- 4条件のどれか1つでも明記が欠けたら、ランクを付けない
- B・C は「あり」の明記が根拠になる。これは掲示義務の対象なので、公式サイトの記載・現地の掲示のどちらでも確認しやすい

## 3. 記録するもの（frontmatter または施設データ）

| 項目 | 内容 |
|---|---|
| `onsenRank` | `S` \| `A` \| `B` \| `C` \| `unrated` |
| `dilution` | `none` \| `yes` \| `unknown`（加水） |
| `heating` | `none` \| `yes` \| `unknown`（加温） |
| `circulation` | `none` \| `yes` \| `unknown`（循環） |
| `disinfection` | `none` \| `chlorine` \| `other` \| `unknown`（消毒。`other` は方式を注記） |
| `rankBasis` | `official-web` \| `on-site` |
| `rankCheckedOn` | 確認日（YYYY-MM-DD） |
| `rankEvidenceUrl` | 公式WEBの場合、ページのURL |
| `rankEvidenceText` | 公式WEBの場合、該当文言（原文のまま） |
| `rankEvidencePhoto` | 現地確認の場合、掲示の写真（ファイル名）。無くても確認の事実と日付は必須 |

- `onsenRank` は4条件から**導出する**（手で入れない）。4条件のどれかが `unknown` なら `unrated`

## 4. 表示文言

- 公式WEB由来：`[Rank] — as stated by the facility (checked YYYY-MM)`
- 現地確認由来：`[Rank] — checked on site by Wayside Japan (YYYY-MM)`
- 公式WEB由来は**施設の自己申告**である旨を必ず出す
- B・C のバッジは、評価語や警告色（赤）を使わない。中立の色で、条件の事実（"chlorinated" "recirculated"）を添える
- 凡例ページ、またはバッジのツールチップに、上の「定義が独自である理由」と、ランクが衛生評価ではない旨を置く

## 5. 運用ルール

- **再確認は12か月ごと。** 期限を過ぎたランクは外して `unrated` に戻す（検査スクリプトで検出する）
- 施設から誤りの指摘があれば、確認のうえ訂正・取り下げ。訂正履歴を残す
- B・C のランクは**根拠（URLと原文、または現地の確認日）が残っているものだけ**表示する。根拠なしでの表示は禁止
- 本文でも、B・C の施設に評価語（悪い・避けるべき等）を使わない。書くのは条件の事実と理由（出典つき）のみ
- 効能は断定しない。公式に示された適応症の範囲で（`onsen-quality` メモ参照）

## 6. 未確認事項（後で詰める）

- 温泉法施行規則10条の逐語照合
- 都道府県の公衆浴場条例・旅館業法の側面（消毒の義務づけ範囲）
- 塩素濃度の数字が現行か
- **B・C を名指しで表示することの景品表示法・名誉毀損上の整理**（事実の表示である限り低リスクと考えられるが、専門家確認を推奨）
- 英語の公式案内に「かけ流し」の説明が無い（JNTO・環境省の英語パンフ）。サイト側で英語の説明を作る必要がある
