## 0. この計画の根拠

推測ではなく公的統計から引いている。数値の出所は末尾。

### 滞在日数（観光・レジャー目的、2025年）

平均 **7.1泊**。分布は 3日以内7.4% ／ 4〜6日45.0% ／ 7〜13日34.9% ／ 14日以上12.8%。

国籍で全く別の話になる。

| ドイツ | 15.2 | 67.1% |
| イタリア | 13.4 | 49.7% |
| オーストラリア | 13.2 | 55.3% |
| スペイン | 13.1 | 55.3% |
| 英国 | 12.8 | 52.2% |
| カナダ | 12.5 | 45.8% |
| 米国 | 10.7 | 31.2% |
| 中国 | 6.4 | 4.2% |
| 台湾 | 5.6 | 1.9% |
| 韓国 | 3.4 | 0.6% |

**欧州・英語圏を主要層に置く決定と、地方を主体にする決定は、ここで噛み合う。** 東京・京都・大阪だけなら6日で足りる。7泊目以降は行き先を自分で決める余白で、その余白を持っているのが狙う層。

逆に韓国・台湾・中国を狙わない決定も、滞在日数の面から正しい。3〜6泊の層に地方の記事を出しても物理的に行けない。

### 入国に使われる空港（2025年）

成田30.2% ／ **関西26.9%** ／ 羽田14.4% ／ 福岡7.2% ／ 那覇6.0% ／ 中部5.4% ／ 新千歳5.1%。主要7空港で約95%。

※ 二次情報。記事に載せる前に一次（出入国管理統計）で取り直す。

### 訪問地の構成（成田・羽田・関空の出国時調査、複数回答）

関東58.8% ／ 近畿12.5% ／ 中部9.5% ／ 九州3.7% ／ 東北2.0% ／ 中国1.6% ／ 北海道1.2% ／ 沖縄1.1% ／ 四国0.5%。

**関西から入った26.9%が、近畿12.5%で止まっている。** この差が、西日本の柱を最優先にする理由。

### 次にやりたいこと（今回との差）

温泉入浴 +24.4pt（27.0→51.4）／ スキー +15.0 ／ 四季の体感 +13.8 ／ 自然体験 +11.7 ／ 旅館 +9.6。
一方、繁華街の街歩き −44.2、ショッピング −33.9。

**リピーターが次に探すものが、このサイトの差別化と一致している。**

### 最も満足した飲食

肉料理32.5% ／ ラーメン19.7% ／ 寿司13.7% ／ 魚料理9.7% ／ そば・うどん4.4%。
**寿司ではなく肉が1位で、寿司の2.4倍。** Eat の配分は 肉 → ラーメン → 寿司 の順にする。

## 1. 設計：日数 × 入口空港で12本

日数は 16 / 12 / 10 の3本立て。上の分布にそのまま対応する。

| 日数 | 中心になる読者 |
|---|---|
| 16日 | フランス・ドイツ（14日以上が67%） |
| 12日 | 英国・豪州・カナダ・イタリア（46〜55%） |
| 10日 | 米国・ロシア・インド（31%前後） |

入口は4つ。中部を独立させた（**A案**）。中部国際空港から四国へは関空経由より遠回りで、実際の人の流れは中部・北陸に向かう。地理に合わない束ね方をすると記事の中身が破綻する。

**四国は単独の柱にしない。** 訪問地0.5%で市場が薄いので、西日本16日と九州16日の派生として扱う。

## 2. ルート骨子

泊数配分と価格は入稿時に確定する。ここは「どこを通すか」まで。

### W16｜関西から16日・山陽山陰四国

関空 → 大阪 → 京都 → 姫路・岡山 → 尾道・しまなみ → 広島・宮島 → 山口（萩・津和野）→ 松江・出雲 → 高松・直島 → 松山・道後 → 関空

16日あるので**山陰と四国の両方を入れられる**。これができるのは16日の柱だけで、他の日数との差別化そのもの。

### W12｜関西から12日・瀬戸内

関空 → 大阪 → 京都 → 岡山・倉敷 → 尾道 → 広島・宮島 → 松山・道後 → 関空

瀬戸内エリアパス（7日）がちょうど収まる。**既存のパス記事が直接ぶら下がる柱。**

### W10｜関西から10日・関西＋広島

関空 → 大阪 → 京都 → 姫路 → 広島・宮島 → 尾道 → 関空

定番に広島を足す形。競合が最も厚いが母数も最大。**パスは買わないほうが得になる場合がある**ことを明記する（この正直さがパス記事への信用になる）。

### E16 / E12 / E10｜成田・羽田から東日本

E16：東京 → 日光 → 会津 → 仙台・松島 → 平泉 → 角館・乳頭温泉 → 弘前・青森 → 新潟 → 東京
E12：E16 から山形・新潟を落とす
E10：東京 → 日光 → 仙台 → 平泉 → 銀山温泉 → 東京

**温泉の比重を最も高くできるのが東日本。** 乳頭・銀山・鳴子は「次にやりたいこと」1位の温泉と直結する。

### K16 / K12 / K10｜福岡から九州

K16：福岡 → 長崎 → 熊本・阿蘇 → 黒川 → 由布院・別府 → （フェリーまたは新幹線で）高松・直島 → 松山・道後 → 福岡
K12：福岡 → 長崎 → 熊本・阿蘇 → 黒川 → 由布院・別府 → 福岡
K10：福岡 → 長崎 → 熊本 → 由布院・別府 → 福岡

**K16 の四国区間が、四国の受け皿になる。**

### C16 / C12 / C10｜中部から中部・北陸

C16：中部 → 名古屋 → 高山 → 白川郷 → 金沢 → 和倉 → 福井（永平寺・恐竜）→ 京都 → 大阪 → 中部
C12：中部 → 名古屋 → 高山 → 白川郷 → 金沢 → 福井 → 中部
C10：中部 → 名古屋 → 高山 → 白川郷 → 金沢 → 中部

**最後に着手する。** 入国5.4%で、既存記事も土地勘の優先順位も低い。

## 3. 1本の構造

モデルルートのテンプレート（Artifact キャンバスの ITINERARY）に流す。

1. **想定読者を冒頭で宣言**（16日・フランスから・初訪日）
2. **What I would change** — 自分で欠点を書く。完璧な旅程は宣伝に見える
3. **費用の内訳** — `researched` では「参考価格」と明示する
4. **Day 1〜N** — 各日に 運賃・所要・乗換・その日の支出
5. **短縮案・延長案** — 12日ならどこを切るか
6. **空港からの入り方／出方**
7. **出典** — パス料金は公式、宿は実勢の参考値

### 根拠の型

**柱は `basis: researched` で書く。** 時刻・料金・パスの条件は鉄道会社の公式ページという一次情報が取れるので、出典2本の条件は自然に満たせる。

瀬戸内の区間は実際に乗っているので、**後から `visited` に昇格できる**。2本立てにしておいた効き目はここに出る。

### 価格の扱い

`researched` では実費を書けない。「参考価格」として、**何の値か・いつ時点かを必ず添える**。
パス料金＝公式の定価（確認日つき）、宿＝実勢の目安（幅で書く）、食事＝一般的な価格帯。

## 4. 枝記事

柱1本につき枝5〜8本。柱が枝の受け皿になり、枝が柱へ戻す。

```
W16（柱）
 ├ 区間：KIX to Hiroshima、3通りの比較
 ├ 区間：尾道からしまなみ海道
 ├ 温泉：道後温泉（入れ墨・タオル・英語対応・駅から）
 ├ 温泉：玉造温泉
 ├ 食：広島のお好み焼き、並ばない時間帯
 ├ 食：岡山・倉敷の肉
 └ パス：瀬戸内エリアパスは元が取れるか ← 既存
```

**12本の柱 × 枝5〜8本で、合計70〜100本。** 週10本で3か月の規模。

### 枝の型（優先順）

| 型 | 根拠 | なぜ強いか |
|---|---|---|
| 空港→目的地の区間比較 | 公式の時刻・料金 | 検索意図が固く、パス・座席・eSIM に近い |
| 温泉（施設情報型） | 施設の公式 | 「次にやりたいこと」1位。入れ墨・タオル・英語を競合が構造化していない |
| 肉・ラーメン | 店の公式・実勢 | 満足度1位と2位。寿司より需要が大きい |
| 旅館 | 施設の公式 | 次にやりたいこと +9.6pt。宿のCTAが直接乗る |
| 季節（紅葉・桜・雪） | 気象・自治体 | 四季の体感 +13.8pt。ただし鮮度管理が増える（後回し） |

## 6. 入稿フォームに足すもの

モデルルート型を入稿できるようにする。

- **記事型**：ガイド／コラム／**モデルルート** の3タブ目
- **日数**（16/12/10/その他）
- **入口空港**（関西／成田・羽田／福岡／中部）
- **日別ブロック**：Day N ＋ 移動・運賃・所要・乗換・宿泊地・その日の支出
- **短縮案・延長案**の欄
- **想定読者**（国・初訪日かどうか）
